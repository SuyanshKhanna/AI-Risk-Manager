Tooltip

Hover or focus (Tab) to reveal the explanation

PR-AUC Area under the Precision-Recall curve. Better than ROC-AUC for imbalanced fraud datasets because it focuses on the minority (fraud) class. settlement_verified Whether the payment gateway returned a SUCCESS callback within the expected 60-second window, confirming the transaction settled. block_threshold Fraud probability threshold above which the decision engine issues a BLOCK action, rejecting the transaction outright. Currently set to 0.70.
